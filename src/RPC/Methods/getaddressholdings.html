getaddressholdings

getaddressholdings

Returns information related to a specific address, detailing the holdings for each asset. This includes DigiByte, represented as asset index 1, if the storenonassetutxo setting is enabled.

Input Parameters

address (string): The blockchain address for which holdings information is requested.

Output Format

JSON object with asset indexes as keys and quantities as values:
{
    "1": 100000,        // Example for DigiByte if included
    "2": 150,
    "3": 300,
    ...
    "digidollar": 2500  // DigiDollar held, in cents. Only present if non zero.
}

Quantities are in the asset's smallest unit — sats for assetIndex 1, which is DigiByte itself. Only unspent holdings are counted, and an index whose unspent total is zero is omitted rather than reported as 0, so every key present represents something the address actually holds.

DigiDollar is not a DigiAsset and has no assetIndex, so it is reported under the reserved non numeric key digidollar, in cents (100 == $1.00). The key is only present when the address holds DigiDollar, so callers iterating this object must either expect a non numeric key or filter for it explicitly.

Examples

digiasset_core-cli getaddressholdings "D7hrf5D21PV24ksEGRdYCZ6JqgsboSVKKC"

curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "getaddressholdings", "params": ["DGb6Bv..."]}' -H 'content-type: text/plain;' http://127.0.0.1:14024/
