digidollarstats

Returns DigiDollar supply, collateral and oracle price over time. Warning: the last result is likely not a full time period.

The series begins at the first window ending at or after the DigiDollar activation height (23,869,440), so it is much shorter than algostats or addressstats. Windows before activation are omitted rather than returned as rows of zeros.

Input Parameters

  • start time (integer, optional): default 0.
  • end time (integer, optional): default maximum.
  • time frame (integer, optional): window length in seconds, default 86400 (one day).

Output Format

JSON array of objects, each containing:
{
    "time": integer,             // end time of the window
    "supply": integer,           // DigiDollar in circulation at window end, in cents
    "supplyAmount": string,      // same value as decimal dollars
    "collateral": integer,       // DGB sats locked in unredeemed vaults at window end
    "collateralAmount": string,  // same value in decimal DGB
    "vaults": integer,           // unredeemed vault count at window end
    "holders": integer,          // addresses holding DigiDollar at window end
    "minted": integer,           // cents minted during the window
    "redeemed": integer,         // cents released by redemptions during the window
    "mints": integer,            // mint transaction count during the window
    "redemptions": integer,      // redemption count during the window
    "transfers": integer,        // transfer count during the window
    "price": {                   // omitted for a window with no oracle commitment
        "min": integer,          // micro USD per DGB
        "max": integer,
        "avg": double
    },
    "ratio": double              // collateral value / circulating value.
                                 // omitted when price or supply is unknown for the window
}

supply, minted and redeemed are DigiDollar cents. collateral is DGB sats. Prices are micro USD per DGB, exactly as the oracles publish them.

Examples

digiasset_core-cli digidollarstats

digiasset_core-cli digidollarstats 1752710400 1755388800 3600

curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "digidollarstats", "params": []}' -H 'content-type: text/plain;' http://127.0.0.1:14024/
