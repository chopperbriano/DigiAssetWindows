getrawtransaction

getrawtransaction

Returns detailed information about a specific transaction in the DigiByte blockchain. The command can return a basic data representation or a more verbose information set including DigiAssets data, depending on the verbose flag.

Input Parameters

  • txid (string): The transaction ID to retrieve data for.
  • verbose (bool, optional, default = false): If true, includes detailed transaction information including DigiAssets data.
  • ignored (ignored, optional): This parameter is not used and can be any value.

Output Format

If verbose is false or not specified:
{
    // Returns a hex string representing the raw transaction data
}

If verbose is true:
{
    "txid": "string",
    "blockhash": "string",
    "height": int,
    "time": int,
    "vin": [
        {
            "txid": "string",
            "vout": int,
            "address": "string",
            "valueS": unsigned int,
            "assets": [ /* Array of assets involved in the input */ ]
        },
        ...
    ],
    "vout": [
        {
            "n": int,
            "address": "string",
            "valueS": unsigned int,
            "assets": [ /* Array of assets involved in the output */ ],
            "digidollar": unsigned int  /* cents carried by this output. only present if non zero */
        },
        ...
    ],
    "digidollar": {                 /* only present on a DigiDollar transaction */
        "type": "string",           /* "mint", "transfer" or "redeem" */
        "cents": unsigned int,      /* total DigiDollar on this transaction's outputs */
        "vault": {                  /* mints only - the collateral being locked */
            "vout": int,
            "collateral": unsigned int,  /* DGB sats locked */
            "minted": unsigned int,      /* cents issued against it */
            "lockHeight": unsigned int,  /* block before which it cannot be redeemed */
            "lockTier": unsigned int
        }
    },
    "issued": { /* DigiAsset issuance details if applicable */ },
    "exchange": [
        {
            "address": "string",
            "index": unsigned int,
            "name": "string",
            "rate": double
        },
        ...
    ],
    "kyc": {
        "address": "string",
        "country": "string",
        "name": "string",
        "hash": "string",
        "revoked": bool
    }
}

Note: The exact fields returned depend on the verbose flag and the transaction details. Asset, DigiDollar and KYC details are only included if applicable.

DigiDollar amounts are always in cents (100 == $1.00), which is the unit the protocol itself uses. A DigiDollar output is a pay-to-taproot output carrying 0 DGB, so its valueS is 0 and digidollar is where the balance lives. DigiDollar fields require the daemon to be running with trackdigidollar=1.

When the request is passed straight through to DigiByte Core, the reqSigs field that v22 and later dropped is reconstructed from the script type for backwards compatibility. That reconstruction covers pay-to-taproot outputs, which report 1 — correct for a key path spend, though a script path spend can require more, which is not knowable from the output alone.

Examples

digiasset_core-cli getrawtransaction "txid1234"

digiasset_core-cli getrawtransaction "txid1234" true

curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "getrawtransaction", "params": ["txid1234", true]}' -H 'content-type: text/plain;' http://127.0.0.1:14024/
