getdigidollarinfo

getdigidollarinfo (height)

Returns the state of DigiDollar as this node has indexed it: the latest oracle price, the amount in circulation, and the DigiByte locked as collateral behind it. With no argument it reports the current state; with a block height it reports the state as of that height.

Requires trackdigidollar=1 in config.cfg. With it off, this method reports nothing. DigiDollar activated at block 23,869,440 — the first run after enabling indexing rewinds to that height and re-scans forward, and until that finishes indexed is false and the figures are incomplete.

Arguments

#NameTypeRequiredDescription
1heightnumericoptionalBlock height to report DigiDollar state as of. If omitted, the current sync height is used.

Result

Returns an object. Every monetary value is present as an exact integer in the protocol's own unit and as a display string — the integer is authoritative, the string is only for showing to people.

NameTypeDescription
activationHeightnumericBlock at which DigiDollar activated on mainnet (23,869,440).
activeboolWhether the chain this node has synced has reached the activation height.
indexedboolCheck this first. False means the activation backfill has not finished, so every figure below is incomplete rather than final.
priceobjectLatest oracle price commitment. Absent if no commitment has been seen yet, which is not the same as a price of zero.
price.microUSDPerDGBnumericPrice exactly as the oracles publish it: micro US dollars per DGB. 4216 means one DGB is worth $0.004216.
price.usdPerDGBnumericThe same price as a decimal, for display.
price.satsPerUSDnumericThe reciprocal, in DGB satoshis per US dollar.
price.heightnumericBlock the commitment was first seen in.
price.epochnumericOracle epoch. One commitment covers 40 blocks, so this changes far less often than the height.
price.timenumericWhen the oracles sampled the price. Runs slightly ahead of the block carrying it.
price.oraclesnumericNumber of oracles that participated in the commitment.
supply.centsnumericDigiDollar in circulation, in cents (100 == $1.00). This is the authoritative value.
supply.amountstringThe same figure as a decimal string, for display only.
supply.holdersnumericAddresses holding a non-zero DigiDollar balance.
collateral.satsnumericDGB satoshis locked in unredeemed vaults.
collateral.amountstringThe same figure in DGB, for display only.
collateral.vaultsnumericNumber of unredeemed collateral vaults.
collateral.rationumericCollateral value divided by DigiDollar supply. Omitted when supply is zero.

Examples

Current state:

DigiAssetWindows-cli.exe getdigidollarinfo

State as of a past block:

DigiAssetWindows-cli.exe getdigidollarinfo 24000000

Errors

ErrorCause
Height above syncThe requested height is higher than the node has indexed.
Not indexedDigiDollar indexing is off (trackdigidollar=0) or has not yet completed its backfill.
