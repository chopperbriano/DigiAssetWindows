## MEDIUM — FIXED (win.118)
- **B-DB4 ✓** The four unsynchronized RAM caches (`_utxoCache*`, `_flagState`,
  `_exchangeWatchAddresses`, `_masterDomainAssetId`) now each have a dedicated
  `mutable` **leaf mutex** (`_utxoCacheMutex`, `_flagStateMutex`,
  `_exchangeWatchMutex`, `_masterDomainMutex`). Each lock is held ONLY around the
  container ops and never across a DB/statement call, so no lock-order inversion
  with `LockedStatement` is possible (consistent order: statement lock → cache
  lock; cache locks are never held while acquiring a statement lock). The
  startup population in the constructor is single-threaded and left unlocked.
  `Database.cpp`, `Database.h`.
- **B-POOL2 ✓** Untrusted peer / discovered-pool `nodes[]` is now re-parsed with
  jsoncpp and rebuilt from a strict whitelist (pool host + numeric lat/lon in
  range + escaped, length-capped city/country), capped at 500 nodes; anything
  malformed yields `[]`. `jsonEscape` also now escapes `<>&` as `\uXXXX`
  (defense-in-depth for the landing-page map). `PoolServer.cpp`
  (`sanitizeNodesArray`).
- **B-POOL4 ✓** A durable sentinel guard row is written to `payouts_ledger`
  BEFORE the payout broadcast (`beginPayoutPeriod`), advancing
  `getLastPayoutAt()` immediately; if the tx broadcasts but the per-recipient
  ledger writes fail — or the process dies between — a re-run is still blocked, so
  no double-pay. The guard is removed (`abortPayoutPeriod`) only on a clean atomic
  failure (nothing sent) so a failed attempt doesn't burn the period. The sentinel
  (`paidTxid` NULL) is invisible to every paid total / count / public list.
  `PoolDatabase.cpp/.h`, `PoolDashboard.cpp`.

Test note: these three aren't in the 82-test unit suite — B-DB4 is a data race
(not deterministically unit-testable), `sanitizeNodesArray` is file-static, and
`PoolDatabase` isn't linked into any test target (wiring it in for one test would
risk the test build). They're covered by the reasoning above + the full suite
confirming no node regression, and are verifiable manually (feed a hostile
`nodes[]`; kill the pool between broadcast and record).
